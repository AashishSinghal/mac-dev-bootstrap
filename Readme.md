# Mac Dev Bootstrap

Bootstraps a new Mac with my development environment.

## Installs

- Xcode Command Line Tools
- Oh My Zsh
- Homebrew
- CLI developer tools
- GUI applications
- nvm + Node LTS

## Usage

Clone the repo or download files.

Make script executable:

```bash
chmod +x bootstrap.sh
```

Run setup:

./bootstrap.sh

The script is idempotent and safe to run multiple times.

Package Management

All packages are defined in Brewfile.

To install or update packages later:

brew bundle

./bootstrap.sh
